
# Employee Management System

A web-based Employee Management System developed using Python and Django.

## Project Overview

This project helps manage employee details easily. Users can add, view, edit, delete, and search employee records.

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap 5
- JavaScript
- SQLite

## Features

- User Login and Logout
- Add New Employee
- View Employee Details
- Edit Employee Details
- Delete Employee Details
- Search Employees by Name
- Filter Employees by Department
- Dashboard with Total Employee Count
- Phone Number Validation
- Responsive User Interface

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/JayanthDev05/Employee-Management-System.git
```

2. Open the project folder:

```bash
cd Employee-Management-System
```

3. Create a virtual environment:

```bash
python -m venv virtual
```

4. Activate the virtual environment:

```bash
virtual\Scripts\activate
```

5. Install Django:

```bash
pip install django
```

6. Apply migrations:

```bash
python manage.py migrate
```

7. Create an admin user:

```bash
python manage.py createsuperuser
```

8. Run the server:

```bash
python manage.py runserver
```

9. Open in browser:

```text
http://127.0.0.1:8000/
```
